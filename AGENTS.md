# AGENTS

CED-ONE is an AI Operating System. Trading is Proof #1 and is governed through
Mission Control. CED-ONE Core and Trading must evolve together.

Purpose:
- Keep the project provider-independent.
- Extend the existing approved Mission Control execution pipeline and reuse native owners.
- Require explicit architecture approval before adding new execution authority or frameworks.
- Preserve a clean, modular Python package layout.

Binding product and safety boundaries:
- Preserve the long-term requirements for specialist orchestration, persistent context,
  autonomous discovery/assessment and controlled adoption of AI tools/models, and secure execution governance.
- AI reasoning must never override deterministic trading-risk gates.
- Unknown or insufficient critical risk evidence must never produce trade approval.
- Analysis execution completion and policy permission to run analysis do not grant trading permission.
- Broker actions, live orders, financial authority and risk-gate changes require separate explicit authorization.
